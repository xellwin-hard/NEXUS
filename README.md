# NEXUS — Sistema de Gestión y Simulación C#

## Descripción del Proyecto
NEXUS es una aplicación desarrollada en **C# (.NET)** utilizando el paradigma de **Programación Orientada a Objetos (POO)**. Este proyecto implementa una arquitectura basada en clases, colecciones y LINQ para la gestión y procesamiento estructurado de datos.

## Requisitos de Ejecución
* **IDE:** Visual Studio Community 2022 o superior.
* **SDK:** .NET Framework 4.8 o .NET 6/8.
* **Lenguaje:** C#.

## Cómo Ejecutar el Proyecto
1. Clona o descarga este repositorio en tu equipo local.
2. Abre el archivo de proyecto `MICION2NEXUSV2.0.csproj` en Visual Studio.
3. Presiona la tecla `F5` o haz clic en el botón **Iniciar** para compilar y ejecutar el proyecto en consola.

## Estructura del Código
* `Program.cs`: Contiene el punto de entrada principal (`Main`), la lógica del flujo ejecutable del sistema y las estructuras POO implementadas.
* `MICION2NEXUSV2.0.csproj`: Archivo de configuración del proyecto en Visual Studio.
