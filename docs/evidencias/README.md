# Evidencias de la entrega NEXUS

Esta carpeta separa los bocetos de diseño de las pruebas reales del proyecto. Los wireframes son propuestas; las capturas de ejecución deben obtenerse al abrir NEXUS y SQL Server en el equipo de desarrollo. No se deben presentar bocetos como si fueran capturas de una aplicación funcionando.

## Capturas que se deben incorporar

Guarda las imágenes PNG o JPG en esta carpeta con estos nombres:

| Archivo | Qué debe mostrar | Cómo obtenerlo |
|---|---|---|
| `01-menu-principal.png` | Menú inicial de NEXUS abierto | Ejecutar la aplicación y capturar la ventana |
| `02-registro-operativo.png` | Registro y selección de clase | Abrir la pantalla de registro |
| `03-hangar-mapas.png` | Hangar o selección de sector | Navegar a esa pantalla |
| `04-exploracion-combate.png` | Arena, HUD y exploración/combate | Iniciar una partida y capturar la pantalla |
| `05-misiones-inventario.png` | Estado de misión e inventario | Mostrar los paneles correspondientes |
| `06-sql-server-tablas.png` | Tablas de NEXUS_DB | Ejecutar el script de ampliación y mostrar las tablas |
| `07-sql-server-registros.png` | Datos de prueba guardados | Guardar una instantánea y consultar las filas |
| `08-github-actions.png` | Compilación automática exitosa | Abrir la ejecución exitosa en Actions |
| `09-repositorio-documentacion.png` | Carpetas docs y evidencias | Abrir la raíz del repositorio en GitHub |

## Criterios

- Las capturas deben ser reales y corresponder al código del repositorio.
- No mostrar contraseñas, cadenas de conexión, tokens ni información privada.
- Evitar recortar mensajes de error si la captura se usa para demostrar una prueba.
- Si una función aún no está integrada, no crear una captura que dé a entender que ya funciona.
- Añadir aquí las imágenes y después enlazarlas desde el README.
